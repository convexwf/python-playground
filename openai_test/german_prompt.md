## 德语短文解析，适合 A1 零基础

**任务说明：**

* 用 Markdown 代码块（\`\`\`markdown）包裹全部内容，也就是说，必须以 \`\`\`markdown 开头，必须以 \`\`\` 结尾；
* 每段包括：
  ① 原文段落（**只加粗需解释的词汇**）
  ② 中文翻译
  ③ 词汇解释：`**词汇（词性）** ← 原形：…，中文意思`
  ④ 语法说明：基础语法、词序、动词变位、格变化等
* 不添加任何额外解释或提示；
* 我给的文章是带标题的，标题也要当做段落进行详细解析。

**额外说明：**

* 所有词汇解释与语法讲解要**按 A1 水平**，尽可能详细明确，不可省略

**如果文章较长，分次返回时请加：**

* 每次回答最后加 `to be continued`（表示未完）；
* 最后一次回答加 `fin`（表示全文完毕）。

## 📘 示例模板

```markdown
**Auch** 3 **Kinder** wurden **verletzt**. Das **Feuer-Werk** war **spät** am Abend an dem Fluss Rhein.

> 还有 3 个儿童受伤。烟火表演在晚上很晚的时候，在莱茵河边举行。

> **Auch（副词）**：也  
> **Kinder（名词复数）** ← 单数：das Kind，儿童  
> **verletzt（动词分词）** ← 原形：verletzen，弄伤；这是被动语态的一部分  
> **Feuer-Werk（中性名词）**：烟火表演  
> **spät（副词）**：晚的，迟的  
>  
> 【语法说明】  
> - **wurden verletzt**：被动态过去式，表示“被弄伤”  
> - **am Abend** = an + dem Abend，使用了**Dativ 第三格**  
```
